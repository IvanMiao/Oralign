# 口语练习架构与能力边界

更新日期：2026-09-24

## 单段练习流程与数据流

```text
本人录音/上传 + 可选一句话目标
  ├─ POST /api/analyze
  │    ├─ Scribe → 转写与词时间线
  │    └─ Gemini Coach ← 音频、转写、背景 → 0–8 条候选
  ├─ POST /api/tts（点击当前目标的“听动作示范”）
  │    ├─ Gemini planner ← 原句、建议句、观察、听者影响、练习动作
  │    ├─ 服务端校验操作和词索引，编译受限语音控制
  │    ├─ ElevenLabs → 生成示范及词时间
  │    └─ 独立 Gemini check ← 生成音频 + 目标
  │         ├─ 内容匹配、保意及动作均通过 → 返回尝试性示范
  │         └─ 不支持/未通过/检查失败 → 返回 unavailable，不返回音频
  └─ 浏览器局部重说 → 原音与重说自主回听，无服务端 Judge
```

已删除研究模式、三个意图槽表单、真人标注、导出及 `/api/judge`。示范检查只检查生成的参考音频，不是恢复原版/重说的 A/B Judge。

## Live 对话原型

开发环境的 `/live` 页面先向 `POST /api/live/token` 申请短期受约束令牌，再由浏览器使用该令牌直连 Gemini Live WebSocket。浏览器把麦克风音频转为 16 kHz PCM16，发送给 Gemini，同时保留用户音轨；收到的 24 kHz 音频排队播放，并记录已播放的 AI 音轨。双方转写、打断、暂停和恢复由浏览器会话控制器处理。生产环境不签发令牌，`/live` 只显示未开放说明。详见 [Live 会话说明](./live-gemini-d04.md)。

Live 目前没有独立声学分析、证据卡或自动练习效果判断；真人语音往返尚待验收。

## 端点

| 端点 | 方法 | 输入与职责 | 外部调用 |
|---|---|---|---|
| `/api/config` | GET | 非秘密配置状态、模型、大小及录音上限 | 无 |
| `/api/demo` | GET | 无音频的静态示例 | 无 |
| `/api/analyze` | POST | 原录音、可选 takeaway；返回分析会话 | 1 STT + 1 Coach |
| `/api/tts` | POST | `target`、`locale`；返回 `ready` 或 `unavailable` | 至多 1 planner + 1 TTS + 1 check |
| `/api/live/token` | POST | 仅本地开发环境签发短期受约束令牌；检查来源并限制签发频率 | 1 Gemini 令牌请求 |

`/api/tts` 不再接受单独的 `{ text }`。详见 [动作示范契约](./action-reference.md)。

## 模块与信任边界

- 页面不读取永久 API 密钥。单段练习的供应商调用由 Route Handlers 发起；Live 由服务端签发短期受约束令牌，再由浏览器直连 Gemini Live。
- `reference-plan.ts` 校验客户端目标及模型方案。模型只能选动作和词索引，不能直接提供 SSML、音素标签或重写后的合成文本。
- 声音练习从原句构造示范；用词和组织从现有建议句构造。生成后检查听到的内容、原意与动作，不能仅凭结构化 JSON 声称准确。
- Planner 与 check 使用独立调用和固定系统指令，输入中的目标、文本及音频均视为数据。
- `ReferenceProvider` 按会话挂载，按完整目标和界面语言共享结果及进行中的请求。切换目标不会串用音频，结果页和重说页使用相同缓存。
- 结束会话卸载缓存、取消客户端请求；Route Handler 将取消信号传入示范各供应商调用。取消不能撤销已处理的调用或费用。
- 生成音频检查失败时不返回音频，且没有自动再次生成。用户明确重试会重新执行整个示范流程。
- 正常/慢速回听只影响播放器；生成音频检查使用未经变速的声音。
- 音频和转写不主动写入工作台磁盘。第三方数据留存仍取决于账户和合同；日志中的供应商错误详情也应注意，不能等同于已完成生产隐私审计。

## 当前实际限制

- Coach 仍把完整转写和原音同时输入，没有独立听音阶段；声音来源声明不证明诊断准确。
- 候选仍为最多 8 条，仍有 `intent_slot`、证据等级等旧字段；PRD 的最多 3 条及界面简化尚未完成。
- 片段定位依赖转写词时间，单条非法候选目前会导致分析失败；没有按候选降级或一键上下文扩展。
- 连续意群与重音控制均非确定性声学控制；示范音频的 AI 检查也不是人类验证，可能错误放行或拒绝。
- 无重说变化检测、语义保持的重说判定、跨会话历史和真人标注。
- 录音计时上限 180/40 秒已实现；上传只检查格式与大小，尚未核验音频时长。
- 无公网鉴权和持久数据库。公开发布前需处理访问控制、调用限额、实际留存及删除策略。
- Live 仅限本地开发环境；真人语音往返尚待验收，声学证据与练习结果尚未实现。
