# Oralign 口语练习

帮助已经能表达的人发现自己未必察觉的听者负担。默认流程：说一段 → 看重点与听原音 → 听动作示范 → 可选重说、自主回听。

## 已实现

- 录音即可分析，可选填写一句话目标；单人英语录音与本地音频上传。
- 录音最长 180 秒，局部重说最长 40 秒，到时自动停止；上传当前只检查格式和默认 12 MB 大小，尚未校验同等时长上限。
- Scribe v2 转写与词时间线，Gemini 联合音频和转写分析，输出 0–8 条候选。PRD 要求的最多 3 条尚待收敛。
- Top-1 默认展示；原音实际裁切为 WAV，支持正常/慢速、循环和词级高亮；其他建议按需展开。全文转写目前仍默认展示。
- 每条建议有观察、听者影响和单一练习动作；重说页也可播放当前目标的示范。
- 动作示范接收原句、建议句、观察、听者影响和练习动作。服务端规划操作、生成语音，再用独立 Gemini 调用听生成音频、核对内容和动作。
- 检查未通过、不可用或不支持时，不返回生成音频；保留原音和动作提示。不自动重新调用付费服务，用户可明确重试。
- 同一会话、同一目标及界面语言共享示范和进行中的请求。结束会话清空缓存并取消待处理请求；重新生成须主动触发。
- 重说后仅提供原音与本次录音回听，无自动改善评分。
- 无密钥示例不包含原音，不支持真实录音比较。参考生成仍需配置供应商，示例中的含混内容也可能无法通过保意检查。

## 已删除

研究模式、进展/阻塞/请求表单、真人标注、JSON 导出、Judge 面板和 `/api/judge` 已删除。`intent_slot` 等旧 Coach 字段仍存在，不代表研究流程仍可用。

## 动作示范能力边界

| 动作 | 当前实现 | 限制 |
|---|---|---|
| 指定位置短停顿 | Flash v2.5 等受支持模型使用服务端生成的 break 标记；Eleven v3 使用短停顿标签 | 标签不保证实际时长或教学适用性，必须经过生成音频检查 |
| 连续意群 | 保留原词句，移除目标范围内的停顿标点，再核对是否连贯读出 | 没有音素或节奏的精确控制，不保证每次可用 |
| 关键词重音 | 仅在配置 `eleven_v3` 时以大写提示目标词，再检查声音 | 默认 Flash v2.5 返回暂不支持；不自动更换模型 |
| 用词/组织 | 使用已有建议表达，检查是否体现动作且保留原意 | 属于内容表达示范，不冒充声音诊断；含混或补写事实时应拒绝 |
| 音素、舌位或精确发音矫正 | 暂不提供 | 不把普通朗读包装成精准发音示范 |

AI 音频检查仍会出错，页面明确标为尝试性示范。它检查生成音频是否体现目标，不接收或评判用户重说，也没有证明最初摩擦诊断或长期学习效果。详细契约与来源见 [动作示范说明](./docs/action-reference.md)。

## 本地运行

要求 Node.js 20.9 或更高版本，在本目录运行：

```bash
npm install
cp .env.example .env.local
# 按 docs/api-configuration.md 配置密钥和 Voice ID
npm run dev
```

打开 `http://127.0.0.1:4173`。示范除 ElevenLabs key 和 Voice ID 外，也需要 Gemini key 做动作规划和声音检查。

## 代码与数据边界

- `app/api/`：配置、演示、录音分析、动作示范四类端点。
- `lib/providers.ts`：Gemini、Scribe、基础语音生成适配；`lib/reference-provider.ts` 编排动作示范。
- `lib/reference-plan.ts`：验证目标、约束动作和词范围、编译供应商控制标记。
- `components/workbench/ReferencePractice.tsx`：会话内共享示范、加载/失败状态和播放入口。
- 原音、重说和示范在当前页面内存中使用，刷新或结束不恢复；服务端不主动写入录音或示范文件，密钥仅在服务端。
- 无账户、公网鉴权或持久数据库。本地不落盘不等于第三方零留存。

待实现：独立听原音的 Coach 对照、目标重说自动检查、上下文扩展、隐藏提示、轻量用户反馈和更完整的结束总结。当前代码能力与 [PRD](../prd.md) 的目标要求应分别理解。
