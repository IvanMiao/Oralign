# Gemini 与 ElevenLabs 调用预算

更新日期：2026-09-16。当前流程已删除研究模式、真人标注、JSON 导出与重说 A/B Judge；早期按研究阶段分配额度的方案不再适用。

## 当前一次动作的调用量

| 用户动作 | ElevenLabs | Gemini |
|---|---|---|
| 载入静态示例 | 0 | 0 |
| 分析原录音 | 1 次 STT | 1 次 Coach |
| 首次准备一个可用示范 | 1 次 TTS | 1 次动作方案 + 1 次生成音频检查 |
| 方案判定动作不支持 | 0 | 1 次动作方案 |
| 播放缓存示范、录制或回听重说 | 0 | 0 |
| 主动重新生成 | 重新计算该次示范调用 | 重新计算该次示范调用 |

一次分析加一次成功示范为 `1 STT + 1 TTS + 3 Gemini`。检查失败仍可能已经产生 TTS 费用，但不返回该音频。没有自动重试，也没有固定金额保证；实际费用依赖模型、音频和文本长度及账户价格。

同一会话内按完整目标和界面语言共享参考结果及进行中的请求。切到重说页不会再次生成；切换语言或明确重新生成可能新增调用。结束会话清理缓存，之后不承诺复用。

## 使用原则

- 优先用少量真实声音与受控对照检查声音判断和动作示范；不再为独立研究 UI、批量 Judge 或导出流程分配预算。
- 默认保留现有配置的 TTS 模型；只有显式设置 `ELEVENLABS_TTS_MODEL=eleven_v3` 才尝试重音路径。
- 录制最长 180 秒，局部重说最长 40 秒；上传目前只检查 12 MB 大小与格式，时长检查仍待实现。
- 不为所有候选自动生成示范；用户按需触发。
- 每次供应商请求按 `API_TIMEOUT_MS` 超时。中止等待不保证供应商未扣费。
- 给密钥设置合适的配额，按供应商控制台核对实际用量；模型自报的质量不能替代回听核对。

## 额度与账户

具体 credits 是否适用于当前 API、计费项目和套餐，以账户控制台及当前官方条款为准，不根据总余额推断可用额度。配置方法见 [API 配置](./api-configuration.md)。

核对入口：[Gemini Billing](https://ai.google.dev/gemini-api/docs/billing)、[ElevenLabs API](https://elevenlabs.io/pricing/api)。
